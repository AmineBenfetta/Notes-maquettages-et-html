# Note sur HTML 

## Savoir se documenter.
Il existe nombres de documentation sur html, une documentation les plus populaire est **MDN** qui est une documentation ultra complète de HTML de ses balises et aussi d'autres languages comme CSS ou JS. 

## "Trinité du web" HTML, CSS et JS.
 
  ### Les différences entre HTML, CSS et JS.
  - HTML
    - Html comporte le contenu textuelle pur du site internet.
  - CSS
    - Css s'occupe uniquement du style du site internet, (couleurs;animations...).
  - JS
    - Js est le language utilisé pour la partie fonctionnalités avancés, (données;boutons...)
